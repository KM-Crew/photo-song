# 🎵 색의 노래 — 내 사진은 어떤 노래일까?

사진을 넣으면 색과 분위기를 읽어 짧은 노래로 들려주는 웹. 로그인·설치 없음, 휴대폰·PC 모두.

**체험:** https://km-crew.github.io/photo-song/

## 어떻게 노래가 되나

| 사진에서 읽는 것 | 노래에서 정하는 것 |
|---|---|
| 분위기(밝기·선명함) | 장조/단조, 빠르기 |
| 왼쪽 → 오른쪽으로 읽은 밝기 흐름(세로줄 16칸) | 멜로디(8마디) |
| 따뜻한 색/차가운 색 | 악기(줄 소리·피아노·종소리) |
| 가장 넓은 색 | 중심음 |

- 같은 사진은 같은 기기에서 언제나 같은 노래입니다(난수 없음).
- **링크로 보내기**: 사진이 아니라 곡 설정값(51~79자)만 링크에 담습니다. 받은 사람은 사진 없이 같은 노래를 듣습니다.
- 사진은 이 기기 안에서만 읽고 어디에도 올리지 않습니다.

## 화면

| 주소 | 화면 |
|---|---|
| `#/` | 첫 화면 — 사진 고르기(PC는 끌어다 놓기·붙여넣기도), 예시 그림 3개 |
| `#/song` | 내 사진의 노래 — 사진 위 스캔 막대, 16칸 색 띠, ▶ 듣기(Space), 설명 카드, 링크 공유 |
| `#/song?s=…` | 받은 노래 — 사진 대신 색 악보 그림으로 같은 노래 |

| 파일 | 하는 일 |
